# Payroll Management System

This project describes a proposed web-based system for a payroll management solution. It automates employee salary calculations, tax deductions, and payslip generation.

The project files are:

* **System_Request.docx** : the project sponsor, business need, requirements, expected value, and special issues.
* **System_Request.pdf** : a portable document format for `System_Request.docx`.
* **Feasibility_Analysis.xlsx** : the technical, economic, and organizational feasibility review.

The figures in the feasibility analysis are estimates for this class assignment. They are not real business data.
